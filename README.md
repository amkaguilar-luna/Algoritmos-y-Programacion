# Algoritmos y Programación
## 📚 Listas y Listas Múltiples en Python
## 🎯 Objetivo
Comprender el uso de las listas y listas múltiples en Python para almacenar, organizar y manipular datos mediante algoritmos sencillos

## 🔹 Listas
Una lista permite almacenar varios elementos dentro de una sola variable.

Ejemplo
productos = ["Laptop", "Mouse", "Teclado"]

## ¿Qué es una lista múltiple?

Una lista múltiple es una lista que contiene otras listas. Se utiliza para representar estructuras como tablas, matrices o asientos de un cine.

Ejemplo
cine = [
    ["1", "2", "3"],
    ["4", "5", "6"],
    ["7", "8", "9"]
]
